Django ORM — Cheatsheet

db manipulation

Consultas básicas

Todos los registros
Post.objects.all()
Filtrar
Post.objects.filter(status='pub')
Excluir
Post.objects.exclude(status='draft')
Obtener uno (lanza excepción si no existe)
Post.objects.get(id=1)
Primero / Último
Post.objects.first()
Post.objects.last()

Field lookups

# exact (default)
filter(name='Ana')
# contiene (case-insensitive)
filter(name__icontains='ana')
# comparaciones
filter(age__gte=18)
filter(age__lt=30)
filter(age__range=(18, 65))
# fechas
filter(created__year=2024)
filter(created__date=date.today())
# nulos
filter(deleted_at__isnull=True)
# lista
filter(status__in=['a','b'])

Crear y guardar

Crear + guardar en un paso
p = Post.objects.create(
    title='Hola Django',
    status='draft'
)
Instanciar y luego guardar
p = Post(title='Hola')
p.status = 'pub'
p.save()
get_or_create
obj, created = Post.objects.get_or_create(
    slug='mi-post',
    defaults={'title': 'Mi post'}
)
update_or_create
obj, created = Post.objects.update_or_create(
    slug='mi-post',
    defaults={'title': 'Nuevo'}
)

Actualizar

Un objeto
p = Post.objects.get(id=1)
p.title = 'Nuevo título'
p.save()
Solo ciertos campos (eficiente)
p.save(update_fields=['title'])
Bulk update (una sola query)
Post.objects.filter(
    status='draft'
).update(status='pub')
Incrementos atómicos (F expressions)
from django.db.models import F

Post.objects.filter(id=1).update(
    views=F('views') + 1
)

Eliminar

Un objeto
p = Post.objects.get(id=1)
p.delete()
Bulk delete
Post.objects.filter(
    status='draft'
).delete()
Todos los registros
Post.objects.all().delete()
⚠ delete() en queryset es irreversible y no dispara señales por objeto. Usarlo con cuidado.

Ordenar y limitar

Ordenar ASC / DESC
Post.objects.order_by('created')
Post.objects.order_by('-created')
Slicing (LIMIT / OFFSET)
Post.objects.all()[:10]      # LIMIT 10
Post.objects.all()[10:20]   # OFFSET 10
Conteo y existencia
Post.objects.filter(status='pub').count()
Post.objects.filter(id=1).exists()

Relaciones

ForeignKey — hacia adelante
post.author          # objeto Author
post.author.email
ForeignKey — reversa
author.post_set.all()
author.posts.filter(status='pub')
Filtro cruzando relaciones
Post.objects.filter(
    author__email='x@x.com'
)
select_related (JOIN, FK/OneToOne)
Post.objects.select_related('author')
prefetch_related (ManyToMany / reversa)
Post.objects.prefetch_related('tags')
💡 Siempre usá select_related / prefetch_related para evitar el problema N+1.

Agregaciones y anotaciones

aggregate — resultado único
from django.db.models import Avg, Count, Max, Min, Sum

Post.objects.aggregate(
    total=Count('id'),
    promedio=Avg('views')
)
# → {'total': 42, 'promedio': 130.5}
annotate — por fila
Author.objects.annotate(
    num_posts=Count('post')
).order_by('-num_posts')

Q objects — OR / AND / NOT

from django.db.models import Q

# OR
Post.objects.filter(
    Q(status='pub') | Q(featured=True)
)

# AND explícito
Post.objects.filter(
    Q(status='pub') & Q(views__gte=100)
)

# NOT
Post.objects.filter(
    ~Q(status='draft')
)

values y values_list

Diccionarios (menos memoria)
Post.objects.values('id', 'title')
# → [{'id':1,'title':'...'}, ...]
Tuplas
Post.objects.values_list('id', 'title')
# → [(1, '...'), ...]
Lista plana de un campo
Post.objects.values_list(
    'id', flat=True
)
# → [1, 2, 3, ...]

Operaciones bulk

Crear muchos en una query
Post.objects.bulk_create([
    Post(title='A'),
    Post(title='B'),
    Post(title='C'),
], batch_size=100)
Actualizar muchos en una query
posts = list(Post.objects.filter(...))
for p in posts:
    p.status = 'pub'

Post.objects.bulk_update(
    posts, ['status'], batch_size=100
)

Transacciones

Context manager
from django.db import transaction

with transaction.atomic():
    cuenta.save()
    movimiento.save()
    # si falla → rollback
Decorador
@transaction.atomic
def transferir(origen, destino, monto):
    ...
